# 👥 NewGen RH

O **NewGen RH** é uma aplicação web fullstack desenvolvida para gerenciamento de colaboradores e folha de pagamento, permitindo o cadastro, atualização, consulta e gerenciamento de informações de funcionários por meio de uma interface moderna e integrada a uma API REST.

O projeto foi desenvolvido com foco na aplicação prática de conceitos de desenvolvimento FullStack, integração frontend/backend, persistência de dados e boas práticas de engenharia de software.

---

## 🎯 Objetivo do Projeto

O objetivo do projeto foi desenvolver uma solução digital para gestão de recursos humanos, simulando um sistema corporativo capaz de realizar operações administrativas relacionadas a colaboradores e folha de pagamento, além de aprofundar conhecimentos em arquitetura FullStack e desenvolvimento colaborativo.

---

## ✨ Funcionalidades

✅ Cadastro de colaboradores  
✅ Atualização de informações de funcionários  
✅ Consulta e listagem de registros  
✅ Exclusão de dados (CRUD completo)  
✅ Integração entre frontend e backend  
✅ Consumo de API REST  
✅ Interface responsiva e componentizada  
✅ Navegação dinâmica entre páginas  
✅ Feedback visual para ações do usuário  
✅ Persistência de dados em banco relacional

## 🚀 Como Executar o Projeto

### Clonar o repositório

```bash
git clone URL_DO_REPOSITORIO
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
npm run start:dev
```
